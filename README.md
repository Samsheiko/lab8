# # Шейко Семён Группа ИТС-1 Лабораторная №6





## Задание 













#### Разработать консольное приложение с дружественным интерфейсом с возможностью выбора
заданий для работы с «базой данных (БД)», хранящейся в бинарном файле. Перечень полей
(минимум 5), достаточно полно характеризующих заданную в варианте предметную область,
предложить самостоятельно (постараться отразить в перечне полей такие, которые требуют разных
типов данных). Приложение должно выполнять следующие функции:
1. Чтение базы данных из бинарного файла.
2. Просмотр базы данных.
3. Удаление элементов (по ключу).
4. Добавление элементов.
5. Реализация 4 запросов (формулировки запросов придумать самостоятельно). 2 запроса
должны возвращать перечень, 2 запроса одно значение. Расписание автостанции






### Алгоритм решения



######



#### 1. Запуск программы
Программа загружает расписание из бинарного файла bus_schedule.dat. Если файла нет, создается пустой список рейсов. После этого открывается главное текстовое меню.
2. Работа с базой данных
- Просмотр: Выводятся все рейсы, отсортированные по времени отправления с помощью LINQ (OrderBy).
- Добавление: Проверяется корректность ввода, создается объект BusRoute, добавляется в список и перезаписывается в файл.
- Удаление: Рейс ищется по ID с помощью LINQ (FirstOrDefault), удаляется из списка, после чего файл обновляется.
- Запросы: Выполняются 4 LINQ-запроса (выборка рейсов по городу через Where, поиск бюджетных мест, подсчет суммы мест через Sum и поиск самого дешевого рейса).
3. Сохранение данных и обработка ошибок
Данные считываются и записываются по полям через BinaryReader и BinaryWriter (с конвертацией даты).
